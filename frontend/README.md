# matchIT — frontend

React 19 + Vite single-page app for matchIT.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run lint
```

The API base URL defaults to `http://localhost:8000/api`. Override it with
`VITE_API_URL` in `.env.local`.

See the [main README](../README.md) for the full setup guide.
